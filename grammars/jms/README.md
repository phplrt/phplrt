# JMS Serializer Type

The type language of [jms/serializer](https://github.com/schmittjoh/serializer),
written in a `@Type` annotation and a `#[Type]` attribute.

Read off its [`Type/Lexer.php`](https://github.com/schmittjoh/serializer/blob/master/src/Type/Lexer.php)
and `Type/Parser.php`. Licence: MIT.
