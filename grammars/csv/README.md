# CSV

Comma-separated values: a line break separates the rows, a comma separates the
fields, and a quote inside a quoted field is written twice.

Grammar written after [RFC 4180](https://www.rfc-editor.org/rfc/rfc4180); the
sample is from the [ANTLR v4 collection](https://github.com/antlr/grammars-v4/tree/master/csv).
