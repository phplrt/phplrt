# PCRE

The pattern a Perl-compatible regular expression is written of, without the
delimiters and the modifiers around it.

Taken from [`hoaproject/Regex`](https://github.com/hoaproject/Regex/blob/master/Source/Grammar.pp),
the grammar [phpstan-src](https://github.com/phpstan/phpstan-src/blob/2.2.x/resources/RegexGrammar.pp)
ships a fork of. Its lexer states are folded into single expressions here.
