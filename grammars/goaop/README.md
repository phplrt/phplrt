# Go! AOP Pointcut

The pointcut language of [Go! AOP](https://github.com/goaop/framework), selecting
the methods, properties and classes an aspect is woven into.

Ported from the BNF of the [Go! AOP IDEA plugin](https://github.com/goaop/idea-plugin/blob/1.2.1/src/com/aopphp/go/parser/pointcut.bnf).
