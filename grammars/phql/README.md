# PHQL

The query language of the [Phalcon](https://phalcon.io) ORM: a query written of
models and their fields rather than of tables and their columns.

Written after [`c/parser.php.lemon`](https://github.com/phalcon/phql/blob/master/c/parser.php.lemon),
with the operator spellings taken from `src/Scanner/Opcode.php`. Licence: BSD-3.
