# Doctrine Query Language

The object query language of the [Doctrine ORM](https://www.doctrine-project.org),
reading entities and their fields rather than tables and their columns.

Written after the [DQL EBNF](https://www.doctrine-project.org/projects/doctrine-orm/en/current/reference/dql-doctrine-query-language.html)
of the ORM documentation. Licence: MIT.
