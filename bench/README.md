# Benchmarks

Comparisons of phplrt against the tools that solve the same problem, written
for [phpbench](https://phpbench.readthedocs.io).

The directory is a project of its own: it is not part of the phplrt package and
has its own `composer.json`.

```bash
composer install

php vendor/bin/phpbench run --report=default    # what it costs them
```
